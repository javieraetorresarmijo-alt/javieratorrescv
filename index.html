Ejercicios del curso

Trabajos realizados durante el curso de Confección y Publicación de páginas web (IFCD0110).

  1. 01 Examen responsive Maquetar un documento a partir de un texto e imágenes dados, adaptándolo a tres puntos de corte (600, 740 y 1024px) y añadiendo animaciones CSS al pasar el ratón. HTML CSS Responsive Animaciones Ver →
  2. 02 Web del centro Forma-TIC Sitio informativo de un centro de estudios con menú y submenús, galería de imágenes, mapa de Google Maps, formulario de contacto y enlaces a redes sociales. HTML CSS Formulario Google Maps Ver →
  3. 03 Calendario 2026 con tablas Calendario anual en un solo HTML: doce tablas de 580 x 360 px, una por mes, alineadas de dos en dos y con un menú para navegar entre meses. HTML CSS Tablas Ver →
  4. 04 CSS responsive Escribir solo el CSS para que con documento ya maquetado se adapte a todos sus puntos de corte, sin tocar el HTML. CSS Responsive Media queries Ver →
  5. 05 Cuestionario interactivo Test de cinco preguntas sobre HTML, CSS y JavaScript que corrige cada respuesta al instante, con un panel de resultados, avisos según el acierto y una tabla donde se guardan los intentos de cada usuario. HTML CSS JavaScript DOM Ver →
  6. 06 Juego del ahorcado Juego de la frase oculta para dos jugadores: valida el nombre y la frase, ignora tildes y mayúsculas, lleva la cuenta de aciertos y errores, permite volver a jugar desde una ventana de diálogo. HTML CSS JavaScript Eventos Ver →
